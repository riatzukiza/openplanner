application sources, npm lock, dependencies, original build and tests are

verification. The new pnpm lock is resolved for this bounded workspace rather
than copied from the broad synchronization. No unrelated application, web UI,
agent package or legacy source import is selected.

recall laws and released exports, and checks actual zero-warning compiler
